# AIAO-Chanと、あるこう。

8th Wallの配布エンジン（SLAMあり）とthree.jsで動くスマートフォン向け6DoF WebAR。補修済みVRMを使用し、MToon・髪と衣装のSpringBoneを維持します。

## 使い方

iPhoneのSafari / AndroidのChromeでHTTPSの公開URLを開く →「カメラで会いにいく」→ カメラとモーションを許可 → 明るく模様のある床をゆっくり映す → 目印が出たら「ここに置く」。左の柔らかいスティックをドラッグすると、その方向に歩きます。浅く倒すと歩行、中ほどで走行、深く倒すと高速走行へ切り替わります。「ジャンプ」で1回跳び、着地後に再び跳べます。置き直し・3段階のサイズ変更に対応。

6DoFは端末の位置・向きの追跡です。配置後の移動は配置地点の水平面上で行い、現実の壁・段差・家具との衝突や遮蔽は行いません。FEATURE_POINTから配置地点を推定するため床を狙ってください。真っ白な床・暗所・動く物体は追跡しにくい場合があります。追跡ロスト時は移動を停止します。

デスクトップの「3Dで遊んでみる」はカメラなしの操作確認です。ARの代替動作や6DoF検証結果ではありません。

「表情を見る」で目8種・口10種・眉5種を組み合わせ、各0〜100%で確認できます。「通常に戻す」でリセット。「顔を近くで」は3Dモード専用です。表情は移動・ジャンプと同時に使えます。

## 開発

Node 22.12以上。

```sh
npm ci
npm run build
npm run dev
npm test
```

初回buildで8th Wall binaryをpublic/engineへコピーします。`dist/` 全体をGitHub Pagesの公開ブランチ直下に配置。`base: './'`なのでリポジトリ名付きURLに対応します。APIキーや有料ホスト契約は使いません。PagesはHTTPSで配信してください。

GitHub操作は `npm run gh -- <args>` でmo84dan5の既存認証を使用します。認証情報はファイルに保存しません。gh標準コマンドのアカウントはグローバル設定でありディレクトリ単位ではないため、このラッパーがappの操作アカウントを固定します。

## モデルとライセンス

公開用モデルは表情制作済みBlendから23種の表情を含めて書き出し、テクスチャを最大1024pxに縮小。元の制作VRMは変更しません。形状・UV・アルファ・MToon・骨・揺れ設定を保持。元の高解像度データは制作プロジェクトに保持。モデルの権利を第三者へ新たに許諾するライセンスは設定していません。`public/models/provenance.json`にハッシュを記録。

待機・歩行・走行・高速走行・ジャンプにはユーザー提供のFBXを使用します。Mixamoの骨をVRMの正規化骨へ対応させ、水平移動はスティックが担当します。制作キットのコードや同梱モーションは配布しません。8th Wall binaryの独自ライセンスとMIT依存ライブラリの表記はアプリ内「このアプリについて」にあります。

## 検証

`npm test`は移動のデッドゾーン・速度制限・方向・追跡ロスト停止・大きなフレーム間隔、XR8ライフサイクルを確認します。実端末のカメラ権限、床配置、回り込み、追跡復帰、熱とフレームレートは別途スマホで確認が必要です。

無操作時は提供されたIdle.fbxをループ再生します。初期画面と、移動停止・ジャンプ完了後の待機にも使用し、モーション間を滑らかに切り替えます。
